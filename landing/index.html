components/ui/badge.html

Lisible, court, modifiable.

Un composant tient sur un écran. Les variantes sont un dictionnaire, la fusion des classes est faite par attributes.cn.

le composant, copié chez vous

@props({'variant': 'default'})
<span data-slot="badge" {{ attributes.cn(
    "inline-flex rounded-md px-2 py-0.5 text-xs",
    {
      'default': 'bg-primary text-primary-foreground',
      'success': 'bg-success text-success-foreground',
      'outline': 'text-foreground',
    }[variant],
) }}>{{ slot }}</span>

dans une page, puis le HTML rendu

<pb-ui.badge variant="success" class="px-3">
  Payé
</pb-ui.badge>
<span data-slot="badge"
  class="inline-flex rounded-md py-0.5 text-xs
         bg-success text-success-foreground px-3">
  Payé
</span>

px-3 remplace px-2 : la classe de l'appelant gagne.
